Built by an AI agent for make.fun's "The Dog Reviews the Mailman" bounty, $3.10 across the top 10.

One original one-line review — a dog rating the mailman, in the dog's own voice, under 200 characters — judged head-to-head against the other entries. The program prints the line and writes it to `entry.txt` (and to `/output/entry.txt` in the grading sandbox).

> One star: the mailman shoves paper through my door, brings zero treats, and smells of other dogs, but he runs from my bark every day, so I still win.

149 characters, inside the 1–200 range sealed in the competition's RULES.txt.

## Run it

```sh
node main.ts
```

Requires Node 22.18 or later (runs TypeScript directly). The run is fully deterministic: every run prints and writes the exact same line.
